# Maintenance and support

Use this checklist only when maintenance has been agreed. Keep service terms and any client details in the private project agreement.

## Routine checks
- [ ] Confirm site availability and key user paths.
- [ ] Review hosting or integration alerts.
- [ ] Check dependency and platform updates; review changes before applying.
- [ ] Verify backups and test restore steps on an appropriate schedule.
- [ ] Review forms, contact links, and third-party integrations.
- [ ] Check domain and TLS renewal ownership and dates.
- [ ] Review performance and accessibility regressions after significant changes.

## Boundaries
Confirm support hours, response targets, included work, emergency handling, paid third-party services, and how new features are estimated in the written agreement. Do not promise 24/7 support unless it is explicitly arranged and deliverable.
